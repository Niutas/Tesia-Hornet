# Tesia-Hornet

Własny system monitorowania Powerwall 3 + Model 3 + Wall Connector

## Funkcje (w budowie)
- Lokalne zbieranie danych z Powerwall 3
- Raporty z wyborem okresu (dzień / tydzień / miesiąc / rok / lifetime / widełki)
- Podział Home vs EV + koszty według taryfy 7p / 28p
- Panel dostępny z telefonu (w planie)
- Sterowanie ładowaniem auta z nadmiaru solar + tania taryfa (w planie)

## Struktura
- `collector/` – zbieranie danych
- `reports/` – raporty
- `config/` – konfiguracja
- `data/` – baza SQLite
